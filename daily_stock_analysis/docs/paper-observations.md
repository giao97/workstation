# 独立模拟观察：建议归档与不操作对照

入口：决策信号页 → 某条建议详情 → **独立模拟观察（不交易）**。先显式填写模拟股数、底仓、现金及费用假设，冻结当前建议；后续点击“检查后续观察”。不需要实际买卖，不连接券商，不修改真实持仓、成本、费用、共享预算或投资档案。不新增定时任务，也不自动把所有信号纳入样本。

本专题暂无英文对照文档；新增界面提供中英文。首版仅支持美元计价、纽约时区的美股/ETF；不是 A 股或跨币种回测。

## 此版本验证什么

`paper-window-v1` 是固定窗口的**方向反事实观察**：

1. 从服务器真实归档时刻（UTC）冻结原建议完整序列化内容、状态、来源、理由及模拟参数；不使用旧报告日期回填归档日期。
2. 归档所在纽约日期**之后**的首个交易日开盘模拟操作。即使盘前归档，也不使用同日开盘。`buy/add` 模拟买入；`reduce/sell` 模拟卖出已有机动股；其他动作保留为未成交。
3. 分别在第 1、3、5、10 个交易日收盘尝试反向恢复相同股数。四个窗口是四个独立情景，不是一笔资金连续操作四次。
4. 与保持相同期初股数和现金不操作比较，扣除两边假设费用、不利滑点；不挑选最好的窗口，也不把四个结果累加。

日线版本**不执行原建议的条件价格、限价、止盈止损或分钟结构**，不能把本结果宣传为原策略回测、做T触发验证、真实成交或胜率。分钟规则使用下面的独立版本，不覆盖日线版本结果。

旧信号可在今天归档，但只观察今天之后；信号在归档时已非 active，或在模拟入场之前到期，结果为未成交。归档后源信号的修改不会改变既有快照，此规则是独立情景，不跟随新的真实建议失效或反向信号。选样是人工且存在选择偏差，不能据此宣称全部信号的总体成绩。

## 模拟约束

- 参数全部必填，费用0需显式填写。买卖费用分别是**指定数量整笔交易的全部费用/交易税假设**，不是已核实致富收费表；不能将15股样本费用自动套到20股或其他标的。费用说明不得填账号/密钥。
- 价格：买价乘 `(1 + 滑点bps/10000)`，卖价乘 `(1 - 滑点bps/10000)`。只作不利滑点，不虚构买卖价差精度。
- 期初现金与股数为独立研究参数，不取真实账户余额。不可融资/做空；卖出不得碰保护股；不得增加本金补救买不回。
- 结算只是冻结的模型规则：假设期初现金已结算；当日卖出所得不能用于同日买回，隔交易日按 T+1 假设释放。这不是致富正式账户类型/实际资金可用确认。
- 模拟数量不得超过该操作日**前一个完整交易日**成交量0.1%，不偷看操作日最终量来决定入场；事后操作日全部成交量仍不足以支持该数量时，不虚构成交。这是保守研究过滤，不是盘口容量或开收盘可成交保证。历史日量充足也不能证明开盘/收盘实际有足够对手盘。
- 现金或流动性不足：第一腿不成交为 `no_fill`；第二腿失败为 `open`，只按期末价给持仓估值差，不宣称成功降本；期末零成交量时连估值差也留空。未平仓不跨窗口/实验自动接续，不自动追补。
- 未计现金利息、个人所得税或账户特有未建模成本，不生成收益率、年化收益或盈利概率。

```text
相对不操作 = 模拟期末现金 − 期初现金 + (期末股数 − 期初股数) × 期末收盘价
恢复原股数后经济降本/股 = 完整往返净现金差 ÷ 期初股数
```

期初0股时基准是保留现金，不计算底仓降本；负数表示更差。机会损失是跑输不操作的部分，不是未来最大风险。

## 单时段分钟条件回放（paper-minute-v1）

在同一入口将“模拟规则”改为“单时段分钟条件回放”。这是**截止时间之后的历史回放**，不是持续盘中监控、即时操作提示或券商订单。规则由用户显式填写，系统不从旧研报自动猜测可执行价位，也不声称这些规则已经验证最优。

### 事前冻结

- 除原模拟资金/费用参数，还须填写 `entry_price`、`exit_price`、`invalidation_price`、带时区的 `expires_at`；不能自行指定历史开始时间。Web日期框使用本机时区，提交转换为UTC；界面同时显示该时区和归档后的UTC截止值。
- 买入/加仓建议：`失效价 < 入场上限 < 退出下限`；减仓/卖出建议：`回补上限 < 入场下限 < 失效价`。只接受 active 的方向性建议。规则有效期不得超过源建议有效期。
- 截止时间必须在未来7天内的一个美股常规交易时段、按分钟对齐，不能超过当天收盘（含半日市）；同一实验不跨交易时段。非交易日或无法核验日历时不创建分钟实验。
- 开始时间取“归档后下一个完整分钟”与“该时段开盘后一分钟”中的较晚者，并预留至少两个观察分钟。多取前一分钟作成交量参考；它即便包含归档前信息，也**不能触发入场**。
- 价格规则、版本、开始/截止时间一并参与原快照哈希。同键同参数重试返回原归档，同键更改模式或条件报错；改参数必须创建新的独立样本，不覆盖失败结果。

### 撮合顺序

1. 第 t 分钟**收盘**满足价格条件才确认：买入 `close <= entry_price`，卖出 `close >= entry_price`；退出方向相反。仅影线触价不会成交。
2. 最早在第 t+1 分钟**开盘**尝试全数量成交，先检查开盘是否已越过失效价，再计入不利滑点，并检查滑点后价格仍满足冻结上限/下限。这是未额外模拟数据发布、决策和下单延迟的理想化分钟边界；订单是研究假设，不保证开盘实盘能成交。
3. 模拟数量不能超过**前一分钟成交量1%**，也不能超过成交分钟事后全部成交量；这是容量假设，不偷看成交分钟最终量来调节数量，且不等同于开盘盘口流动性。没有盘口队列、买卖报价、部分成交或撮合优先级模型。
4. 未成交候选只在下一分钟尝试一次；若价差/资金/成交量不满足，记录拒绝。后续新的收盘确认可以在截止前再触发一次尝试，但不会改变数量/本金/边界。一轮完成即停止，最多两笔模拟成交。
5. 分钟开盘的成交在其后高低点检查**之前**入账，不能因该分钟后来走坏而删掉亏损入场。失效价触及后永久停止该实验撮合；若同分钟同时触及退出/回补及失效区间，标记顺序不确定，不假设有利顺序，不记成功往返。已经由前一分钟确认并在本分钟开盘完成的退出，不受其后无敞口的高低点追溯取消。
6. 失效是“停止继续撮合”，**不是已模拟执行的止损订单**；不强制平仓、不追高回补、不因到期追加资金。已入场但未恢复股数的情况保留为 `open`，按截止前最后一个完整分钟收盘给未闭合估值差；最后一分钟零量则估值差也留空。

同日卖出款不能为同日回补提供已结算资金，只能使用模拟期初已结算现金；买入使用期初已结算现金，退出只卖新增数量，不侵犯保护底仓。本版本不核实真实券商账户规则，也不把模拟资金与真实账户预算混合。每股经济降本仍只在恢复期初股数且期初股数大于0时计算；手续费大于价差造成的亏损照常记录。

### 分钟数据与证据

- 只在截止时间后15分钟运行；此前为 `pending` 且不取分钟行情。单次手动检查，不新增定时任务。应用保守限制为从预热分钟起6天内取数；超过窗口为 `blocked`，不使用日线、5分钟线或插值补出历史1分钟线。
- 复用同一原始行情适配器，以 `interval=1m` 取明确UTC区间，关闭复权、修复、盘前盘后；检查证券代码、USD/纽约市场元数据、时区、严格递增连续分钟、OHLC与成交量、取数时刻及公司行动。缺一根分钟线（包括无成交导致提供方省略该分钟）、重复、乱序或多返回区间外分钟均暂停核算，不跳过缺口凑成功。
- 同时检查该交易日至取数日的日线公司行动覆盖；缺应有交易日记录、分红或拆股时不算收益。这可能使次日盘前尚无日线时保守阻断，或让之后发生的分红阻断未留档的较早观察；不会改写已留档终态。不能把第三方漏报/修订风险视为已消除。
- 首次终态保存分钟线、日线公司行动证据、冻结时段、每笔模拟成交/确认分钟、拒绝/失效事件、来源、取数时间和哈希。之后读取原结果，不用修改后的行情重写；`pending/blocked` 可以重试。
- `horizon=0` 专指单时段分钟回放，非“0个交易日收益”；它与原1/3/5/10日窗口在不同引擎版本下隔离。多个样本是独立资金假设，不能累加为组合业绩或混入真实成交报表。

分钟条件是手工选择的研究规则，仍有选择偏差；不是对整篇自然语言研报的自动解释或完整策略验证。想证明有效仍需事前固定选样、足够前瞻样本及可靠行情/账户证据，不输出胜率保证。

## 数据与留档

- 复用既有交易日历，严格检查完整交易日（含节假日、半日市、夏令时），收盘后保留15分钟发布缓冲；不是实时行情验证。缺日线不跳过缺口凑满N天。
- 独立调用已安装 yfinance 的日线入口，明确 `auto_adjust=False/back_adjust=False/repair=False/actions=True`，不影响既有行情适配器的优先级或缓存。**不读取 StockDaily 复权缓存**，无替代源时返回 `blocked`。
- 显式检查证券代码、美元/纽约市场元数据、OHLC、重复/未来日期、取数时间、成交量及公司行动。`auto_adjust=False` 本身不保证不含拆股调整；从入场前一交易日至本次取数期间发现分红、拆股或资本利得分配时暂停未完成观察，避免混用价差和总回报。后续分红可能保守阻断较早尚未核算窗口。
- 第三方可能漏报或修订数据。每个窗口第一次终态（completed/open/no_fill）的输入日线、来源URL、取数时刻、输入哈希与输出都会独立留档；刷新不覆盖历史终态，也不以修订后的数据重写好看结果。哈希证明内容一致性，不证明提供方内容正确。
- `pending/blocked` 不写为永久收益结论，可以手动重试。超过归档一年停止新取数；已留档终态仍可读。当前界面显示该信号最近50个实验，无跨实验汇总；不同实验可以共用相同假设资金，不能当真实资金组合累加。

## API 与兼容

- `POST /api/v1/paper-observations`：`signal_id`、`request_key`、`assumptions`，可选 `minute_rules`（上述四字段，额外字段拒绝）。省略或null保持原日线模式。请求键重试返回同一归档，不更新源快照；同键参数变化返回400。开始时间只能由服务器决定。
- `GET /api/v1/paper-observations?signal_id=...&limit=50`：查询归档，最多100条。
- `POST /api/v1/paper-observations/{id}/evaluate`：仅抓取观察数据并持久化模拟终态，不交易。
- `GET /api/v1/paper-observations/{id}/evidence/{horizon}`：按冻结版本读取证据；分钟版使用 `horizon=0`，包含分钟及日线公司行动证据。尚无该窗口终态返回404。

沿用既有应用认证；新增表 `paper_experiments`、`paper_outcomes` 由现有 create_all 增量创建，不修改原方向结果 `decision_signal_outcomes` 或真实成交表，也不新增配置。正式账户规则未确认不阻塞纯模拟开发，但模拟结果不能直接升级为可执行订单。

回滚：恢复本功能涉及的代码并重新构建Web，保留两张新增表即可，旧应用忽略它们。不要删除真实账本或清空数据库。测试使用临时数据库、合成日线/行情；上线前仍需检查外网行情可达性和提供方元数据完整性。

分钟功能没有新表、迁移或环境变量。仅回滚分钟代码时可保留全部档案，日线旧引擎会将分钟归档识别为不支持的规则版本，不重新解释成日线；恢复新版可继续读取其证据。既有认证、日线API和真实持仓功能不变。专题仍仅中文（无现有英文文档），UI提供中英文。
