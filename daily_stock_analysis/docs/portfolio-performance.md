# 波段收益与持续持有对照

入口：持仓页 → “波段收益与持续持有对照”。这是一项**只读区间复盘**，不是择时信号、订单或未来盈利预测；不修改持仓、券商成本、预算、费用证据或资金确认。本专题暂仅中文，无现有英文对照文档；Web新增界面提供中英文。

## 范围与基准

选择账户、明确起止日期（均包含，按交易所日期，最长367天）和可选标的。留空标的时，只列期间有成交或公司行动的证券；也可选有账本记录但期间无交易的持仓，不把自选股或未记录标的猜成零仓位。

- 纳入选定区间该证券的**全部成交**，不自动识别“策略交易”，也不挑选盈利单。如果区间内混有长期加仓，结果包括这部分，不可宣称是纯做T收益。
- 期初股数取开始日前一日账本，期末股数取结束日账本，复用已有期初基线与库存回放；不得从当前成本或投资档案反造历史买入。已有期初基线的账户，复盘起点必须晚于该日末基线。
- 用户需明确确认期初持仓、区间全部成交及公司行动记录完整。确认仅用于本次核算，不替代券商验证，不写回账本。所有费用与税费仍需各成交标为 `confirmed`，不能用一个复盘勾选跳过费用核实。
- 对照组为保持期初股数和相同初始现金不操作；期初零股时，对照是保留现金，不是“在首次买入价买入并一直持有”。
- 入金、出金不计收益；不推断结算资金或允许做T额度。不同币种分别核算，不做隐含汇率换算。多账户或重叠日期的结果不可直接累加。

## 公式

令 `Q0` 为期初股数，`Q1` 为期末股数，`P` 为合格期末参考价格：

```text
毛现金差 = 卖出成交金额合计 − 买入成交金额合计
净现金差 = 毛现金差 − 本区间买卖两边已确认费用及税费
相对不操作的差额 = 净现金差 + (Q1 − Q0) × P
```

卖出所得本金不是利润；未恢复的股数在对照组仍然值钱，不能漏掉右边的持仓估值差。真实成交价已包含实际成交滑点，不再重复扣除假设滑点；不猜测未来回补/平仓费用。

- **已恢复股数且有交易**：`Q1 = Q0`，期末价格在对照中抵消，净价差收益等于净现金差，无需实时价。该算式在完整、无公司行动的区间成立，不要求为了算价差伪造分钟成交时间。亏损往返同样计入。
- **尚未恢复股数**：单列净减少/净增加股数，完整往返净收益和降本均留空；有合格期末价时才给“含未闭合估值差”的参考对照，不叫已兑现利润。
- **经济回本价改善**：仅在股数恢复、费用核实、记录完整且 `Q0 > 0` 时为 `净价差收益 ÷ Q0`。负数表示经济回本价恶化。不等于券商显示的平均成本，也不把其他证券的利润摊到本证券。
- **无期间交易**：交易贡献可为0，但不记成一次成功往返，不计算降本。

示例仅供测试，不写入个人账本：

| 场景 | 正确解释 |
| --- | --- |
| 105股底仓，卖20再买回20，净价差17.89美元 | 改善约0.170381美元/基准股，不是按20股摊薄全部成本 |
| HAL从0股买10再卖10，毛差0.60、假设已核实两边费用2.05美元 | 净贡献−1.45美元，对照保留现金；没有HAL底仓成本可降低 |
| VOO从1股加到2股 | 属于净增持，不是已完成做T；不能将毛现金流出说成已实现亏损 |
| 卖20股只回补10股，剩余10股上涨 | 将未恢复股数的价值扣入对照，不能只展示回笼现金或已回补部分盈利 |

## 数据质量与参考估值

- 手续费未知或估算：展示毛现金差与“已记录费用”，完整净收益、对照和降本留空。`null` 不是0。费用修改后需重新核算，源流水版本及账本指纹会变化。
- 分红、拆股：本版本不具备完整权益登记、预扣税和股数调整基准，遇到区间内相关公司行动就暂停该证券对照和降本，不用价差冒充总回报。
- 尚未闭合时，只有明确勾选、期末为对应交易所今日，才尝试复用已有行情适配器读取参考价；不定时轮询。必须有来源与时间戳、同一币种、报价不超过5分钟、未标为陈旧，并且报价不早于当日已录入成交。今日成交时间未知则不能核验该先后关系。
- 本轮不把数据库中未标明复权口径的历史收盘价用作历史未闭合对照，也不拿今天报价回填过去。历史已恢复股数的现金差仍可计算。日/韩/台未闭合估值暂不支持，相关结果显式缺失。
- 请求途中取得的行情可能并非同一秒，合计仍只是同次查询的参考估值。页面刷新持仓或修改复盘范围后隐藏旧结果，需重新计算。
- 本结果不是券商税务批次盈亏、账户总收益率、年化收益、胜率或策略有效性证明；未计现金利息、个人所得税及未入账的其他成本。没有资金加权/时间加权收益分母时，不制造收益率。

## 合计与可追溯性

按币种给出可比较数量、区间证券数、已核实闭合部分净价差与完整范围对照。只要任一证券的对照未知，该币种完整合计为 `null`；可展示已核实闭合子集，但明确子集数量，不把子集当整个组合成绩。每股降本不跨标的相加。

每个结果带原成交编号、时间、数量、价格、费用状态和版本，相关公司行动，期初/期末股数，参考价来源/时间，方法版本 `period-hold-v1`、账本指纹及本次证据哈希。它们用于追溯输入，不是券商认证。本阶段不增加报告数据库表、不可变历史存档或自动研报推送；API响应可由调用方保存，页面显示本次快照。

## API、兼容与回滚

```http
POST /api/v1/portfolio/accounts/{account_id}/performance-review
Content-Type: application/json

{
  "start_date": "2026-09-28",
  "end_date": "2026-09-28",
  "symbols": ["EUV", "HAL"],
  "ledger_confirmed": false,
  "include_realtime": false
}
```

POST仅承载显式复盘范围，**不写账本**，沿用现有管理端认证。返回 `items`、`totals_by_currency`、`ledger_fingerprint`、`evidence_hash`、`generated_at` 等；不存在的账户/标的、未来期末日期、超长区间、早于期初基线的起点或异常成交字段返回校验错误。空活动区间返回空列表，不编造往返。

没有新增环境变量、定时任务或数据库迁移，旧API保持兼容。发布时前后端配套；本轮可回滚复盘端点及面板而无需删除任何账表。若同时回滚上一阶段成交/预算能力，仍须遵守[成交核实与预算的升级回滚限制](portfolio-execution-budget.md#6-升级与回滚)。
