# 量化交易系统 - 使用指南 (增强版)

## 一、系统概述

本系统每天自动收集 A股 + 美股 + 港股的行情数据、新闻资讯、政策公告，生成**每日投资总结报告**，包含：

- **市场情绪概览**：综合新闻+政策情绪得分
- **今日要闻速览**：按重要性排序的市场要闻 + 个股关联消息
- **个股深度分析**：技术面 + 增强基本面 + 个股新闻情绪 + 交易信号

## 四、运行系统

### 4.1 全流程模式（推荐）

`powershell
cd C:\Users\PC\workStation\quant-trading-py
python main.py --mode=full
`

执行流程：
1. 抓取行情数据（A股/美股 K线 + 实时行情 + 基本面）
2. 抓取新闻（东方财富/财联社/雪球/新浪/CNBC/Reuters/Yahoo Finance）
3. 抓取政策（证监会/央行/上交所/深交所）
4. 分析每只股票的技术面 + 基本面 + 个股新闻情绪
5. 生成综合交易信号
6. 输出每日总结报告（HTML + Markdown + JSON）

### 4.2 分步执行

`powershell
# 只抓取数据
python main.py --mode=fetch

# 只分析（基于已抓取的数据）
python main.py --mode=analysis

# 只生成报告
python main.py --mode=report

# 只生成纯新闻日报
python main.py --mode=news
`

### 4.3 历史回测

基于已经保存的历史 CSV，验证当前技术信号规则的下一交易日开盘成交表现：

`powershell
python main.py --mode=backtest
`

回测结果输出到 `reports/backtest/`，包含总收益、年化收益、夏普比率、最大回撤、交易次数、胜率、盈亏比和每笔交易明细。

### 4.4 纯新闻日报模式

`--mode=news` 只做新闻链路：抓取新闻、去重、个股关联、情绪与重要度打分，然后输出一份纯新闻日报，**不会**执行行情抓取、基本面分析或买卖点计算：

`powershell
python main.py --mode=news
`

输出文件：

| 文件 | 说明 |
|------|------|
| news_digest_YYYY-MM-DD.html | 纯新闻日报，浏览器打开查看 |
| news_digest_YYYY-MM-DD.md | Markdown 格式 |
| news_digest_YYYY-MM-DD.json | 结构化新闻数据 |
| news_digest_YYYY-MM-DD.txt | 纯文本摘要，适合复制到微信等聊天工具 |

如果本次没有抓到新新闻，会自动使用最近一次缓存的 `data_storage/news/all_news.json` 生成日报。

### 4.5 新闻中文翻译（可选）

英文新闻默认保留原文。配置 OpenAI API Key 并开启后，`--mode=news` 会把英文标题和摘要翻译成中文：

`env
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini
NEWS_TRANSLATE=true
`

参考 `.env.example` 创建 `.env` 后运行即可。未配置 Key 或未开启时，新闻保持原文。

### 4.6 微信推送（可选）

日报生成后可以推送到手机微信，两种方式二选一或都配置：

**方式一：企业微信群机器人**
1. 在企业微信群里添加「群机器人」，复制 Webhook 地址
2. 配置 `WECHAT_WEBHOOK_URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...`

**方式二：Server酱**
1. 登录 [Server酱](https://sct.ftqq.com) 获取 SendKey
2. 配置 `SERVERCHAN_SENDKEY=SCT...`

配置后运行 `python main.py --mode=news`，报告生成完会把纯文本摘要推送到微信。默认最多推送 6000 字符，可用 `NEWS_PUSH_MAX_CHARS` 调整。

> 手机上的 ChatGPT/GPT 客户端不支持外部主动推送；更实际的做法是让 OpenAI 翻译/摘要后走微信或邮件接收，需要分析时再把日报内容发给 GPT。

### 4.7 官方新闻源（可选，推荐）

为了避免第三方页面反爬和 RSS 超时，可以配置官方新闻源，配置后新闻抓取会优先走官方接口，页面抓取只作为兜底：

**NewsAPI（全球财经新闻）**
1. 到 [NewsAPI](https://newsapi.org) 注册获取 API Key
2. 配置 `NEWSAPI_KEY=...`，可选 `NEWSAPI_LANGUAGE=en`、`NEWSAPI_CATEGORY=business`

**Tushare Pro（A股财经快讯）**
1. 到 [Tushare Pro](https://tushare.pro) 注册获取 token（新闻接口需要积分）
2. 配置 `TUSHARE_TOKEN=...`

默认 `NEWS_OFFICIAL_FIRST=true`：只要官方源抓到新闻，就不再抓第三方页面；官方源失败或未配置时才走原来的页面抓取。

## 五、查看报告

报告位置：
`
C:\Users\PC\workStation\quant-trading-py\reports\
`

| 文件 | 说明 |
|------|------|
| daily_summary_YYYY-MM-DD.html | **每日总结报告**，浏览器打开查看 |
| daily_summary_YYYY-MM-DD.md | Markdown 格式，可用记事本/vscode 打开 |
| daily_summary_YYYY-MM-DD.json | 结构化数据，供程序读取 |
| news_digest_YYYY-MM-DD.html | **纯新闻日报**，只含新闻摘要 |
| news_digest_YYYY-MM-DD.txt | 纯文本摘要，适合微信等场景 |

### HTML 报告包含：

1. **市场情绪概览**：综合得分 + 判断（极度乐观/偏乐观/中性观望/偏悲观/极度悲观）
2. **今日要闻速览**：
   - 🔥 高重要性新闻（涉及特朗普/美联储/关税/战争等）
   - 📌 一般重要性新闻
   - 个股关联消息汇总
3. **个股深度分析卡片**：
   - 综合信号（STRONG_BUY / BUY / HOLD / SELL / STRONG_SELL）
   - 当前价格、RSI、MA20、MACD状态
   - 基本面评分（估值/质量/成长/风险/现金流 五维）
   - 数据质量置信度、建议仓位与止损价
   - 关键亮点 ✅ 和风险点 ⚠️
   - 止损位 / 止盈位
   - 个股相关新闻及情绪判断
4. **K 线图**：K 线、MA20、布林带和成交量
5. **组合风险预览**：候选敞口、集中度、行业权重和风险提示

## 六、新闻关联说明

系统会自动将新闻与关注列表中的股票进行关联：

- 通过 STOCK_ALIASES 中的名称/别名进行匹配
- 例如新闻标题包含"茅台" → 关联到 600519
- 例如新闻标题包含"马斯克" → 关联到 TSLA
- 未关联到个股但涉及重大事件（特朗普/美联储/关税等）的新闻会出现在"市场重要消息"中

## 八、自动化运行（可选）

### Windows 任务计划程序

1. 打开 **任务计划程序** → 创建基本任务
2. 名称：QuantDailyReport
3. 触发器：**每天** 上午 9:00
4. 操作：启动程序
5. 程序：C:\Users\PC\AppData\Local\Programs\Python\Python312\python.exe
6. 参数：main.py --mode=full
7. 起始于：C:\Users\PC\workStation\quant-trading-py

### Python 内置常驻调度

`powershell
python main.py --mode=full --schedule 09:00 --run-now
`

`--run-now` 会先立即执行一次，然后保持进程运行并在每天 09:00 重复执行。生产环境仍建议使用 Windows 任务计划程序，让操作系统负责进程重启和开机自启。

每次运行都会写入 `data_storage/runs.sqlite`，用于检查成功、失败、耗时和运行指标。
